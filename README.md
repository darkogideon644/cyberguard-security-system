# cyberguard-security-system

CYBERGUARD v1.0

Personal Account Security Monitoring System

Project Description

CyberGuard is a beginner-level Python cybersecurity simulation designed to monitor account information, analyse failed login attempts, identify potential security threats and generate a security report.
Features

Collects basic user account information.

Monitors failed login attempts.

Detects possible brute-force attacks.

Checks account status (Active or Inactive).

Assesses password strength.

Generates a security analyst report.

Technologies Used

Python 3

Visual Studio Code

Python Concepts Demonstrated

Variables and data types

Strings, integers and Booleans

User input and output

Type conversion

Comparison operators

Conditional statements (if, elif and else)

How to Run the Project

Install Python 3.

Download or clone this repository.

Open the project folder in Visual Studio Code.

Open the terminal.

Run the following command:

python cyberguard.py

Enter the requested account information.

Testing

The system was designed to test three scenarios:

Normal account.

Suspicious account with multiple failed login attempts.

Disabled account.

CyberGuard is an educational cybersecurity simulation. It does not perform real-time account monitoring or actual network security operations.
